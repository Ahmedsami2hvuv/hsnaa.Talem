# معلم حسناء
منصة تعليمية عربية شخصية لمتابعة دراسة السادس الابتدائي.

## التقنية الحالية
- Next.js 15 + TypeScript
- Cloudflare Workers عبر OpenNext
- Cloudflare D1 لقاعدة البيانات
- لا يعتمد المشروع على Supabase أو Vercel أو Railway أو R2 حالياً.

## تشغيل محلي
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. نفّذ `npm run dev` لتشغيل واجهة التطوير.
4. نفّذ `npm run preview` لمعاينة نسخة Cloudflare Workers محلياً بعد إعداد ربط D1.

## النشر
- اربط هذا المستودع بخدمة Workers Builds في Cloudflare.
- أمر البناء: `npm run build:cf`.
- أمر النشر اليدوي: `npm run deploy` بعد تسجيل الدخول إلى Wrangler وإعداد ربط D1.
- أنشئ binding باسم `DB` لقاعدة `hsnaa-db` في ملف `wrangler.jsonc` أو من إعدادات Worker.

## قاعدة البيانات
تم إنشاء قاعدة D1 باسم `hsnaa-db` وإعداد الجداول الأولية من لوحة Cloudflare. يجب ربط معرّف قاعدة البيانات (database_id) بالمشروع قبل استخدام D1 من التطبيق.

## الحالة الحالية
الواجهة الأولية تعمل ببيانات تجريبية داخل المتصفح. إضافة المهام وتحديد الإنجاز محليان فقط حتى تكتمل واجهات API وربط D1. تسجيل الدخول الآمن، صلاحيات ولي الأمر والطالبة، التصحيح الذكي، رفع الصور والصوت والتقارير مراحل لاحقة.

لا تضع مفاتيح أو أسرار أو بيانات دفع داخل GitHub. استخدم Cloudflare Secrets وEnvironment Variables.
