# معلم حسناء
منصة تعليمية عربية شخصية لمتابعة دراسة السادس الابتدائي.

## التقنية
- Next.js + TypeScript
- PostgreSQL + Prisma (قاعدة البيانات على Railway)
- PWA-ready manifest

## التشغيل المحلي
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` وأضف بيانات PostgreSQL.
4. نفّذ `npx prisma generate` ثم `npx prisma migrate dev --name init`.
5. نفّذ `npm run dev`.

## حالة النسخة الحالية
الواجهة التأسيسية تعمل ببيانات تجريبية داخل المتصفح. إضافة المهام وتحديد الإنجاز تعمل محلياً. تسجيل الدخول الحقيقي، حفظ البيانات في PostgreSQL، التصحيح بالذكاء الاصطناعي، رفع صور الدفتر والصوت، والتقارير تحتاج مراحل الربط التالية. لا تضع مفاتيح API داخل ملفات الواجهة أو GitHub؛ أضفها كمتغيرات بيئة في Railway.
